# Align optimizer memory before extending federation

**Investigate shared adaptive optimizer state and fresh global gradient anchors.** This remains a plausible route toward centralized aggregate performance after the earlier interventions failed their criteria; it does not promise rare-class recovery. First establish an exact distributed-gradient/server-Adam bridge to a matched centralized accumulation implementation. Next test one established method, **MIME-Adam**, which combines shared adaptive statistics with local gradient correction. Only if that comparison supports the mechanism should a bounded adaptive-anchor variant try to reduce synchronization cost. The potential contribution is an experimentally supported adaptation for this workload, not a claimed new optimization principle or guarantee of beating centralized training.

## Establish exactly which centralized update federation reproduces

At common parameters `θ`, let client population weights be `p_i=n_i/N`, frozen class weights be `a_y`, and the training-only mean target weight be `μ`. Each client computes `g_i=∇[Σ_(z∈B_i) a_y CE(θ;z)/(|B_i|μ)]`; the server forms `g=Σ_i p_i g_i` and applies **one persistent Adam step**. By linearity of differentiation, a central implementation accumulating the same microbatch losses with exactly those coefficients has the same data gradient, up to floating-point reduction order. Matching initialization, moments, counters, regularization, clipping placement and scheduling then gives a numerical equivalence test. Averaging independently updated Adam moments cannot establish this identity because squaring and adaptive normalization are nonlinear. ([Adam equations](https://arxiv.org/abs/1412.6980))

This bridge is a **weighted accumulation reference**, not automatically an ordinary pooled minibatch mean. With unequal client populations and equally sized client batches, population weights differ from batch-size weights. Preserve population weights and unbiased local sampling to target the population objective in expectation, and reproduce those exact coefficients centrally. Likewise, client-specific observed class-weight denominators generally differ from one common denominator; the existing fixed-denominator objective must be applied to both arms. ([Existing objective specification](../src/models/official_losses.py))

Begin with full participation and a deterministic, dropout-disabled gradient/parameter/moment audit over several steps. Then verify training-mode replay using matched microbatches and stochastic masks; a common seed alone is insufficient. Retain LayerNorm and identical training-fitted preprocessing. Crucially, twenty client gradients followed by one Adam update do not reproduce twenty sequential centralized minibatch updates, whose later gradients and moments have already changed. Therefore compare the accumulated reference's predictive performance with a newly matched ordinary centralized Adam run before attributing any residual gap to federation.

## Test MIME before adapting anchor timing

Choose **full MIME-Adam over MimeLite** because it tests adaptive-state alignment together with gradient correction under the difficult non-IID partition. At anchor `x`, aggregate full client gradients into `c=Σ_i p_i∇F_i(x)`. Local updates use `∇ℓ_i(y;b)−∇ℓ_i(x;b)+c`, with server-supplied optimizer statistics frozen throughout the block; aggregate final models and update server statistics from `c`. MimeLite omits the correction. This is an established comparator, not a renamed project invention. ([MIME, NeurIPS 2021, Algorithm 1](https://proceedings.neurips.cc/paper/2021/file/f0e6be4ce76ccfa73c5a540d992d0756-Paper.pdf))

Its published Adam decomposition uses a lagged second moment, so it is not repeated ordinary `Adam.step()`. Specify moment initialization, epsilon, ordering and bias correction, and check against its precise centralized base updater separately from the standard-Adam bridge. Pair stochastic masks in the same-batch subtraction. The paper's Adam result assumes, among other conditions, zero first-moment coefficient; its stronger centralized-barrier result concerns momentum variance reduction. Neither guarantees CICIoT2023 F1 or false-alert performance. ([MIME, Table 5 and analysis](https://arxiv.org/html/2008.03606))

## Adapt the interval between anchors only after alignment helps

The proposed extension controls **MIME's common block length**. At each fresh anchor, reuse its already collected gradients to calculate relative dispersion `D=√[Σ_i p_i‖g_i−c‖²]/(‖c‖+ε)`. Start with one local step; permit a single predeclared longer block only after repeated low-dispersion observations, and return to one after a high or unstable score. Refresh the anchor and shared statistics at every block boundary. This makes anchors less frequent per local step without treating stale gradients as current evidence.

This controller is **unvalidated**. MIME already cancels anchor disagreement, so raw dispersion might poorly predict subsequent corrected drift; small global-gradient norms also destabilize the ratio. Use fixed-block MIME controls and predeclare how learning rate and moment-update cadence depend on block length. Otherwise a changing effective step size could masquerade as a scheduling benefit. Freeze thresholds, the longer interval and hysteresis on development evidence; stop if the controller stays short or fixed blocks perform equally well.

The closest precedents are MIME and Wang et al.'s JSAC adaptive-communication approach, which uses common-model gradient divergence and resource estimates to choose local intervals. The latter's main theory assumes convex, smooth objectives. The proposed contribution is task-specific validation and cost accounting, not the invention of drift-dependent synchronization. ([Adaptive federated learning, Algorithms 2–3](https://arxiv.org/html/1804.05271))

## Predeclare a new study and charge every anchor

Before implementation or training, freeze a separate protocol using **from-scratch fits** and development/confirmation subsets derived solely from permitted historical training rows. Fit preprocessing and class weights only on the new fit subset, preserve row provenance, and reconstruct client assignments consistently. Reserve confirmation before tuning; nevertheless, previously trained-on rows are not independent untouched evidence. Keep the exposed original final test closed to selection and never present it as fresh. ([Completed-study boundary](full_data_extension/final-closeout.md))

Compare newly matched centralized Adam, the accumulation bridge, ordinary FedAvg and fixed-block MIME before admitting the adaptive extension. Use comparable tuning allowances and paired training/client-partition seeds. Predeclare a practically meaningful macro-F1 gap to centralized performance, benign false-alarm ceiling and allowed per-class regressions. Always report all eight classes' precision/recall/F1, confusion matrices and benign FAR. Rare-class recovery need not be the continuation criterion, but zero recall must remain a stated failure of eight-class detection; accuracy alone cannot establish success.

Conditional payload accounting illustrates the cost: with 20 participating clients, 5,096 FP32 parameters and cached anchor uploads, MIME exchanges four model-sized downloads and two uploads per client: **2,446,080 bytes per block**, excluding overhead, versus 815,360 for FedAvg. This reused-client accounting differs from the paper's separate-cohort accounting. With `N` anchor examples and `W` local examples per block, backward-example work is approximately `N+2W`; full anchors can dominate short blocks. ([Model-size record](federated_class_safeguards/scaffold-findings.md), [MIME communication accounting](https://arxiv.org/html/2008.03606))

Log actual gradient work, examples, updates, bytes, barriers and wall time; compare matched work and matched communication separately. Set the numerical run budget after the design and cost audit. This remains single-machine simulated federation, with unchanged inference architecture and no implied privacy or measured edge-performance guarantee.

## Conclusion

The decisive result is whether retaining globally informed optimizer behavior buys useful predictive quality per resource spent. If the bridge cannot approach the centralized target affordably, or fixed MIME offers no useful trade-off, another controller lacks an evidence-based foundation. This proposal authorizes no training and makes no performance claim.
